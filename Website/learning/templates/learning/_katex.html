{% comment %} KaTeX, client-side. Client-side deliberately: nh3 sanitises server-rendered HTML and would strip KaTeX's generated markup, whereas rendering in the browser happens after sanitisation and is unaffected. The LaTeX reaches here byte-for-byte because render_markdown_text(protect_math=True) stashes math spans around Markdown. `throwOnError: false` means a malformed expression shows in red rather than blanking the page — for a maths site, a visible bad formula beats a blank one. {% endcomment %}
